# Contributing

Issues and PRs welcome on [KolektivComputer/keel](https://github.com/KolektivComputer/keel).

1. Read [AGENTS.md](./AGENTS.md) and [DEVELOPING.md](./DEVELOPING.md).
2. Run `./gradlew :lib:test :ktor:test` and `pnpm test` before opening a PR.
3. Keep page ids stable. Do not invent APIs in docs without a matching host/pack surface.
