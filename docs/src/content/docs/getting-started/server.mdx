Host artifacts live on Nexus at `repo.kolektiv.computer`. Pick **one** Maven
repository:

- `maven-releases`, numbered releases such as `0.1.1`
- `maven-snapshots`, canonical `*-SNAPSHOT` builds

Do not add both. Gradle will mix channels. `maven-public` is an optional
aggregate group if you already resolve other Kolektiv artifacts from it; Keel
itself does not require it.

This page is **core** only (`computer.kolektiv.keel:core`). It has no Ktor
dependency. Protocol format `keel/1`. Seed version `1`.

## Snapshots

Canonical `*-SNAPSHOT` builds resolve from `maven-snapshots`. Point Gradle at
that URL instead of `maven-releases`, and pin the snapshot version you want.

Publishers write numbered releases to `maven-releases` and canonical snapshots
to `maven-snapshots`. You only need the consumer URL you chose.
