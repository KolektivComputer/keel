Host artifacts live on Nexus at `repo.yuri.capital`. Pick **one** Maven
repository:

- `maven-releases`, numbered releases such as `0.1.0`
- `maven-snapshots`, canonical `*-SNAPSHOT` builds
- `keel-maven`, the unique pre-release line such as `0.0.2-SNAPSHOT.4`

A version like `0.0.2-SNAPSHOT.4` is **not** a canonical Maven snapshot:
snapshots end in `-SNAPSHOT`, and `maven-snapshots` rejects every other
version. Do not add more than one. Gradle will mix channels.

This page is **core** only (`dev.kolektiv.keel:core`). It has no Ktor
dependency. Protocol format `keel/1`. Seed version `1`.

## Unique pre-release instead

Current pre-release: `0.0.2-SNAPSHOT.4`. The `-SNAPSHOT.4` suffix is part of
a literal, unique version, not a canonical Maven snapshot, so point Gradle
at `keel-maven`:

```
https://repo.yuri.capital/repository/keel-maven/
```

That is the advertised repository for the pre-release line. Canonical
`*-SNAPSHOT` builds, when published, resolve from `maven-snapshots`.
Publishers always write to `keel-maven`, plus `maven-releases` for numbered
releases or `maven-snapshots` for canonical snapshots. You only need the
consumer URL you chose.
