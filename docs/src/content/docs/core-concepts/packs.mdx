A pack is a `.feb`: a zip whose root is `manifest.json` plus the modules it
names. The manifest maps **page ids** to modules — the pack's implementation
of the <a href={path("/docs/core-concepts/contracts")}>host contract</a>.

Authors write a file tree of pages (ids, not URL routes). The tree below is
Svelte; other adapters swap the component and head extensions and keep the
same folder ids — see
<a href={path("/docs/implementing/framework-adapters")}>Framework adapters</a>:

<FrameworkPanel frameworks="svelte">

```
src/pages/
  +layout.svelte
  harbor/
    +layout.svelte
    home/+page.svelte        → harbor.home
    home/+head.svelte        → harbor.home document head
    user/+page.svelte        → harbor.user
    notFound/+page.svelte    → harbor.notFound
```

</FrameworkPanel>

<FrameworkPanel frameworks="react vue solid preact lit angular">
The folder ids are identical. React, Solid, and Preact use `+layout.tsx` and
`+page.tsx`; Vue uses `+layout.vue` and `+page.vue`; Lit and Angular use
`+layout.ts` and `+page.ts`. All six carry the head in a sibling `+head.html`.
Lit and Angular page modules have no component extension, so a page that needs
a different id adds a sibling `+page.id.ts`.
</FrameworkPanel>

The id is the directory path with `/` turned into `.`. A sibling `+page.ts`
may `export const id = "harbor.home"` when the folder name should not be the
id. `+layout.svelte` files wrap descendant pages, root-first. Route params
like `[slug]` are not ids — the host owns URLs. A sibling `+head.svelte`
(Svelte) or `+head.html` (other adapters) compiles into the page's manifest
`head` — see
<a href={path("/docs/core-concepts/head")}>Document head and SEO</a>.

manifest, and can zip the `.feb`.

The host loads that artifact as a `FrontendBundle` from a **jar resource**, a
**file**, or an **exploded directory** (dev / watch).

<CodeBlock
  lang="kotlin"
  bw="ktor"
  title="FrontendBundle"
  code={`val harbor = FrontendBundle.fromResource("keel/harbor.feb")
val unpacked = FrontendBundle.fromDirectory(Path.of("pack/dist"))
val file = FrontendBundle.fromFile(Path.of("harbor.feb"))`}
/>

Asset URLs are per bundle: `/__keel/pack/{bundleId}/…`. Seed `entry` / `css`
are rewritten to that prefix so multiple bundles on one app do not clash.

Pass `contract` (typegen's `keel/1` JSON) so a pack that implements an
unknown id fails the build. A pack may implement a subset; the call site
passes the pack per route.

The `.feb` layout, `PageModule`, and `RouterAdapter` are specified under
<a href={path("/docs/implementing/pack-adapter")}>Pack adapter</a>.
