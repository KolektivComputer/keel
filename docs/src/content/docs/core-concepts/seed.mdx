The seed is the only **read** model. Document GET places it in
`#__keel_seed`. Visits return it as JSON (`X-Keel-Visit: true`). Bootstrap
parses it and passes a typed context into `mount()`.

```json
{
  "v": 1,
  "page": "harbor.home",
  "path": "/",
  "params": {},
  "data": {
    "viewer": { "id": "ada", "displayName": "Ada" },
    "feed": []
  },
  "errors": {},
  "theme": { "id": "harbor", "version": "0.1.0" },
  "entry": "/__keel/pack/harbor/pages/harbor.home.js",
  "css": ["/__keel/pack/harbor/assets/mount.css"],
  "build": "9f1c6e0b…",
  "host": "#__keel_root",
  "head": {
    "title": "Harbor",
    "description": "An in-memory message board.",
    "canonical": "https://example.com/"
  }
}
```

A Svelte page reads that payload with `page()`. No second fetch.

<CodePair
  fw="svelte"
  title="page()"
  ts={`<script lang="ts">
  import { page } from "@kolektiv/keel-svelte"
  import type { HomePage } from "@app/page-types"

  const ctx = page<HomePage>()
</script>

<p>{ctx.data.viewer?.displayName ?? "Anonymous"}</p>
<p>{ctx.path}</p>
<p>{ctx.page}</p>`}
  js={`<script>
  import { page } from "@kolektiv/keel-svelte"

  const ctx = page()
</script>

<p>{ctx.data.viewer?.displayName ?? "Anonymous"}</p>`}
/>

`theme` is the serving pack's `{ id, version }`; `entry`, `css`, and `build`
come from that pack. `build` is the pack's content hash (also `X-Keel-Build`);
a client whose mounted build differs reloads itself — see
<a href={path("/docs/advanced/pack-hot-reload")}>Pack hot reload</a>.
Optional fields: `shared`, `layout`, `redirect`, `head`. `path` is absolute.
`page` and `entry` are non-blank.

On a document GET the host writes `head` into the HTML shell. Visits return
the same `head` so `<Head>` stays in sync. See
<a href={path("/docs/core-concepts/head")}>Document head and SEO</a>.

Partial reloads (`only` / `except`) filter top-level `data` keys on visits
only — see <a href={path("/docs/advanced/partials")}>Partial reloads</a>.
The field list and `X-Keel-*` headers are on
<a href={path("/docs/implementing/protocol")}>the wire protocol</a>.
